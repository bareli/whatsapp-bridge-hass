# Changelog

## 0.1.1

- Add brand assets (`icon.png`, `logo.png` at 1x and 2x) under
  `custom_components/whatsapp_bridge/brand/`.
- Add README and `info.md` screenshots: QR pairing card and phonebook panel
  (mockups generated by `docs/generate_assets.py`).
- Drop `ignore: brands` from the HACS integration check now that real brand
  assets ship in the repo.

## 0.1.0

- Initial release.
- `notify.whatsapp` platform, custom services (`send_text`, `send_media`,
  `send_location`, `contact_*`, `session_*`).
- `whatsapp_message_received` event for incoming messages.
- Lovelace QR card and sidebar phonebook panel.
- Sensors for connection state, phone battery, last-message timestamp.
- Image entity for the QR code.
- English translations.
