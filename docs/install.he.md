# התקנה

ההתקנה כוללת שני חלקים: התוסף (מריץ את WhatsApp Web) והאינטגרציה (המאגר הזה).

## 1. התקנת התוסף

1. ב-Home Assistant פתחו **הגדרות ← תוספים ← חנות התוספים ← ⋮ ← מאגרים** והוסיפו:

    ```text
    https://github.com/bareli/whatsapp-bridge-addon
    ```

2. התקינו את **WhatsApp Bridge** והפעילו אותו. בהפעלה הראשונה מורד Chromium, וזה עלול
   לקחת כמה דקות.
3. חפשו ביומן התוסף שורה כזו:

    ```text
    Generated API token: <hex>. Save this in add-on options to keep it stable.
    ```

אפשר להדביק את האסימון בלשונית **Configuration** של התוסף כדי שיישמר גם אחרי התקנה מחדש.
אם משאירים את שדה האסימון ריק בעת הוספת האינטגרציה, היא מאחזרת אותו אוטומטית בהתקנה הראשונה.

## 2. התקנת האינטגרציה דרך HACS

=== "חיפוש ב-HACS"

    1. פתחו את HACS וחפשו **WhatsApp Bridge**.
    2. הורידו אותו.

    אם החיפוש לא מוצא אותו, השתמשו בשיטת המאגר המותאם אישית.

=== "מאגר מותאם אישית"

    1. ב-HACS פתחו את תפריט **⋮** בפינה העליונה ובחרו **Custom repositories**.
    2. Repository: `https://github.com/bareli/whatsapp-bridge-hass`
    3. Type: **Integration**.
    4. התקינו את **WhatsApp Bridge**.

הפעילו מחדש את Home Assistant. האינטגרציה רושמת בעצמה את פאנל הצד **WhatsApp** ואת רכיב
Lovelace בשם `whatsapp-qr-card`, ואין צורך בהתקנת תוסף נפרד.

## 3. הוספת האינטגרציה

עברו אל **הגדרות ← מכשירים ושירותים ← הוספת אינטגרציה ← WhatsApp Bridge**.

1. אשרו את אזהרת תנאי השימוש (סימון התיבה נדרש כדי להמשיך).
2. הזינו את פרטי החיבור:

    | שדה | הערות |
    |---|---|
    | Host | ברירת מחדל: `core-whatsapp_bridge` |
    | Port | ברירת מחדל: `8080` |
    | API token | אופציונלי. אם משאירים ריק, האסימון מאוחזר מהתוסף אוטומטית. |

נתמך מופע אחד בלבד של WhatsApp Bridge.

## 4. צימוד הטלפון

פתחו את הערך **WhatsApp** בסרגל הצד: קוד ה-QR מוצג בראש הדף כשהגשר במצב `qr`, `loading`
או `disconnected`. בטלפון פתחו WhatsApp ← **מכשירים מקושרים ← קישור מכשיר** וסרקו אותו.
תוך כמה שניות המצב משתנה ל-**Ready**.

מעדיפים לוח מחוונים? ראו את [כרטיס ה-QR](examples.md#lovelace-qr-card).
