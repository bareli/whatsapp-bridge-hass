# פתרון בעיות

| תסמין | פתרון |
|---|---|
| הכרטיס נתקע על "Initialising" | בדקו את יומן התוסף; ייתכן ש-Chromium עדיין עולה (בהפעלה הראשונה זה לוקח כדקה עד שתיים). |
| שגיאות 401 ביומן של HA | אי-התאמה באסימון. אחזרו את האסימון מאפשרויות התוסף, או הסירו והוסיפו מחדש את האינטגרציה. |
| קוד ה-QR לא מופיע | הסשן כבר מצומד. השתמשו ב-`whatsapp_bridge.session_logout` כדי להכריח צימוד מחדש. |
| `Authentication failed` | הטלפון ניתק את המכשיר. הכריחו צימוד מחדש מלשונית **Settings** בפאנל. |
| Raspberry Pi 3 / armv7 | לא נתמך. השתמשו ב-Pi 4/5 (aarch64) או במארח Intel. |
| "Cannot reach the add-on at that host/port" | ודאו שהתוסף פועל ושהמארח והפורט נכונים. |
| "Token rejected by the add-on" | הדביקו את האסימון העדכני מיומן התוסף או מלשונית Configuration שלו. |
| הכרטיס או הפאנל לא מציגים QR | מזהי הישויות שונים בין התקנות חדשות (קידומת `whatsapp_bridge_`) לישנות; השתמשו במזהים שמוצגים בהתקן שלכם. |
